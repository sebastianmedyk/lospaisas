## What “customer tires” means here

You supply the tires (new or used, as long as they are appropriate for the vehicle). We handle:

- Inspection of size and obvious damage before mounting
- Mounting on your wheels
- Optional **balancing** so the ride is not shaky
- Advice if a tire looks unsafe to install

We stay honest: if a casing has sidewall damage, severe dry rot, or the wrong load rating, we will say so before we put it on the car. Saving money only works if the install is safe.
